# CoreStory GitHub Apps

CoreStory helps teams understand their codebases. We analyze your repositories, map how the system fits together, and turn that into specs, documentation, and answers your team can use.

This organization hosts the GitHub Apps that connect your repositories to CoreStory. When you install one of these apps, you choose exactly which repositories CoreStory can access, and you can change or revoke that access anytime from your GitHub settings.

We keep these apps in a dedicated organization so that ownership and permissions stay clearly separated from our product source code.

Learn more at https://corestory.ai
